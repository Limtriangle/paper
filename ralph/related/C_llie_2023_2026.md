## Which of these report seeds, variance, or multiple runs?

None found. All twenty entries above report single-run point estimates (PSNR/SSIM/LPIPS etc.) in their tables; none of the verified sources (openaccess/ECVA/NeurIPS proceedings pages, abstracts, or GitHub release notes) mention multiple random seeds, averaging over repeated runs, or reported variance/standard deviation for their headline LOL/LOL-v2 results. This is consistent with common practice in the deep LLIE literature, where single-seed results are the norm.
