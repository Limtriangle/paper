# T3 — Test-Time Adaptation for HVI-CIDNet Brightness Collapse

## Verdict: NOVEL-IN-HVI (component-wise assembly, not a new mechanism)
No paper adapts HVI-CIDNet's own knobs (learnable-k density, alpha_s/alpha_i/gamma inverse-transform gains, I-branch norm) at test time via non-reference losses — MILL and NTIRE 2026 only *document* the collapse (26.4→17.7 dB; 13.85 dB zero-shot) and fix it with retraining/flow-matching (LFM-LLIE), not TTA. Every building block is taken, though: Zero-DCE-style non-reference losses (exposure/color-constancy/spatial-consistency/TV) already drive per-image test-time optimization in "Retinex Based Algorithm Unrolling and Adjustment" (self-supervised test-time fine-tuning against a synthesized pseudo-normal-light image) and in SALVE (self-supervised per-video adaptation); per-image gamma/brightness parameter search at test time already exists via genetic/NSGA-II optimization; few-parameter TTA for restoration backbones (SR, all-in-one) is established. Closest single antecedent: the Retinex-Unrolling test-time fine-tuning paper (arXiv 2202.05972) — same mechanism (freeze most of network, adapt at test time with self-supervised/non-reference loss, seconds per image), different color space/architecture and gradient-free-vs-gradient-based genetic alternative (arXiv 2505.11246) for the "tune gamma/exposure knob directly" variant.

## Baseline to beat
Frozen HVI-CIDNet at fixed default inference knobs (alpha_s=alpha_i=gamma=1.0, or paper-reported test-set values) evaluated zero-shot on MILL's brightness-shifted splits and/or NTIRE 2026 unpaired test set: 26.4 dB (in-distribution) → 17.7 dB (20% brighter) → 13.85 dB (NTIRE zero-shot). Secondary baseline: the genetic/NSGA-II gradient-free per-image gamma search (arXiv 2505.11246), to show a gradient-based few-step TTA beats or matches it at much lower cost/iterations.

## Cheapest deciding experiment
Take the released HVI-CIDNet checkpoint, freeze everything except {learnable-k scalar(s), alpha_s, alpha_i, gamma, I-branch norm affine params} — likely under a few dozen scalars. For each MILL brightness-shifted image (or a 20-image subset spanning the 11 intensity levels), run 10–50 Adam steps minimizing a Zero-DCE-style combo loss (exposure control + color constancy + spatial consistency, optionally NIQE) against only those parameters; measure PSNR/SSIM recovery vs. the frozen baseline and vs. wall-clock cost (should be ~1–2s/image on a 2080Ti). A positive result (recovering a meaningful fraction of the 26.4→17.7 dB gap without touching GT) both validates the method and is cheap enough to run before committing to the full paper.

## Locus where it should help
Most directly at the **I-branch intensity path and the inverse-HVI-transform gain/gamma knobs** (alpha_s, alpha_i, gamma) — these are explicitly exposed, currently hand-set constants, and directly control global brightness remapping, so they are the natural low-dimensional target for non-reference-loss test-time adaptation under brightness/domain shift; secondarily the learnable-k density parameter of the Intensity Collapse Function, which governs how aggressively low-light regions are compressed and would need to shift for scenes outside LOL's brightness distribution.
