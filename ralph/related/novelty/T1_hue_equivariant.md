# T1: Hue-equivariant HV-branch for HVI-CIDNet — Novelty Check

## Verdict: NOVEL-IN-HVI
No paper combines rotation-/steerable-equivariant conv layers with the HVI/CIDNet chroma (HV) branch, hue augmentation, and a circular hue loss. But the two halves already exist separately and close together: the equivariant mechanism (hue-as-2D-rotation, lifting/group convs on HSL/HV-like coords) is established by CEConv (NeurIPS'23) and its direct HSL-hue-rotation-group successor "Learning Color Equivariant Representations" (arXiv 2406.09588, 2024-2026), and the exact target problem (low-light color-cast robustness via cylindrical/polar hue-chroma correction) is attacked head-on by CAGE (arXiv 2608.10512, Aug 2026) using a non-equivariant adaptive transform instead. Closest work overall: **"Learning Color Equivariant Representations"** (mechanism) + **CAGE** (application/problem).

## Baseline to beat
HVI-CIDNet (or HVI-CIDNet+) trained with standard augmentation, vs. the same backbone with CAGE's AdaCCT plug-in color-debiasing module — CAGE is the nearest non-equivariant competitor solving the identical low-light hue-bias problem and should be the headline baseline, not just vanilla CIDNet.

## Cheapest deciding experiment
Take released HVI-CIDNet code/weights, apply a synthetic global hue-rotation (white-balance shift) augmentation to a held-out test set (e.g. LOLv2), and measure ΔHue-error / PSNR degradation of stock CIDNet vs. a version where the HV-branch's first conv block is swapped for a CEConv-style hue-rotation-equivariant lifting conv (no retraining of the rest of the network, or minimal fine-tune). A large drop in hue-error variance under rotation for the equivariant variant, with parameter count held roughly constant, would establish the core claim cheaply before building the full steerable/E(2)-style pipeline.

## Locus where it should help
The HV-branch's early feature-extraction layers in CIDNet's dual-branch UNet (before the Lighten Cross-Attention fusion with the I-branch) — i.e., replace the first few standard convs operating on (H,V) with hue-rotation-equivariant/steerable convs there, since that is where global color-cast/white-balance shifts manifest as pure 2D rotations of the (H,V) vector field, before any nonlinear mixing with intensity.
