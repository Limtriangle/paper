\begin{abstract}
\mname \citep{yan2025hvi} enhances low-light images by mapping them into the \hvi
(Horizontal/Vertical/Intensity) color space, processing intensity and chroma along
separate branches, and supervising the output in both RGB and \hvi. This thesis studies a
question about that design; the question, the claims, and the experiments are fixed in the
project plan before any run starts, and every reported number is read from a result file
by a verification script rather than transcribed.
\end{abstract}
