\section{Method and Protocol}
\label{sec:method}

\paragraph{Model.} We use the public \mname implementation \citep{yan2025hvi}. The network
takes an sRGB image, converts it to \hvi, processes the intensity map and the chroma map
along two interacting branches, and converts the result back to sRGB.

\paragraph{Protocol.} All runs share one frozen protocol: the same dataset split, seeds,
optimizer, schedule, and hardware (\hw). Checkpoints are selected on the validation split
only; the test split is read once, by a separate final-evaluation script, per reported
configuration. Each run records the SHA-256 of its training script, the upstream commit,
and the split file.
